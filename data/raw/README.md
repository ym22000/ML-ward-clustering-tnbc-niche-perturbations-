# Source data

The input comes from the authors' processed spatial transcriptomics archive.

- Article: https://doi.org/10.1038/s41467-026-74125-6
- Zenodo record: https://doi.org/10.5281/zenodo.15102983
- Downloaded archive: `visium.rar` (about 22 GB)

After extraction, the analysis reads:

```text
extracted/visium_mouse/processed/mouse_main/*.h5ad
```

Each `h5ad` file is one mouse Visium section. The raw archive is not generated by
this project and should not be committed to a Git repository.
